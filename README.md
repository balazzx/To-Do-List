# To-Do List Application

A simple and user-friendly To-Do List Application developed using HTML, CSS, and JavaScript.

## 📌 About the Project

The To-Do List Application helps users manage their daily activities by adding, completing, and deleting tasks. It provides a simple interface to organize everyday work and improve productivity.

## ✨ Features

- Add new tasks
- Display all added tasks
- Mark tasks as completed
- Delete tasks
- Empty task validation
- Simple and clean user interface
- Responsive design

## 🛠️ Technologies Used

- **HTML5** – Creates the application structure.
- **CSS3** – Provides styling and layout.
- **JavaScript** – Handles task operations and user interactions.

## 📂 Project Structure

```text
To-Do-List/
│
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Enter a task in the input box.
5. Click the **Add Task** button.
6. Click a task to mark it as completed.
7. Click **Delete** to remove a task.

You can also use the Live Server extension in Visual Studio Code.

## 📸 Output

The application displays a task input field and an Add Task button. Added tasks appear below the input field with options to mark them as completed or delete them.

## 🎯 Objective

The objective of this project is to understand HTML page structure, CSS styling, JavaScript DOM manipulation, event handling, and basic user interaction.
